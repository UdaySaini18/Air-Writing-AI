# Air Writing AI

AI-powered air writing project using Python, OpenCV, MediaPipe and Tesseract OCR.
## Features

- Real-time hand tracking
- Air writing using index finger
- Multiple colors
- Gesture-based color selection
- Fist gesture for erasing
- Undo and clear options
- Save drawing
- AI text recognition using Tesseract OCR
- 
## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
- Tesseract OCR
- Pytesseract
- 
## How to Run

Install dependencies:

```## Installation
Install Python 3.12
Clone this repository
Create a virtual environment
py -3.12 -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
Install Tesseract OCR separately
```

## Run the Project

```bash
python air_writing_code.py
```

## Gestures

- Index finger → Draw
- Middle finger → Select color
- Closed fist → Erase
- Open hand → Idle
