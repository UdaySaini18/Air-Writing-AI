# Air Writing AI

AI-powered air writing project using Python, OpenCV, MediaPipe and Tesseract OCR.
## Features

- Real-time hand tracking
- Air writing using index finger
- Multiple colors
- Gesture-based color selection
- Fist gesture for erasing
- Undo and clear options
- Save drawing
- AI text recognition using Tesseract OCR
- 
## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
- Tesseract OCR
- Pytesseract
- 
## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python air_writing_code.py
```

## Gestures

- Index finger → Draw
- Middle finger → Select color
- Closed fist → Erase
- Open hand → Idle
